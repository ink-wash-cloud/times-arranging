# 时序 · 界面设计规范（v1.4.0「清晰版」）

参照对象：**Apple**（premium white space / SF Pro / hairline / 单强调色）。
只借「角色与规则」，不复制任何品牌素材；色彩仍沿用本应用自己的暖色玻璃身份。

来源：skill brand-design-md 的 references/brands/apple/DESIGN.md（token 名沿用其命名），
本文件里标注为「派生」的值是为本应用补的，原文件没有。

## 1. 一条原则

> 屏幕上只允许一个「最响」的东西：一屏里最重要的那一个数字或动作。
> 其它一切都退到第二、第三层：细线分隔、次要灰字、无边框。

## 2. Canvas / 墨色

| 角色 | 值（派生） | 用法 |
| --- | --- | --- |
| --ui-canvas | 沿用主题玻璃底（不新加颜色） | 页面底色 |
| --ui-ink | var(--text)（可读性算法算出来的） | 正文、标题 |
| --ui-ink-2 | var(--dim) | 次要说明 |
| --ui-ink-3 | var(--dim-2) | 三级信息、计数、时间戳 |
| --ui-line | rgba(20,16,22,.08)（ins）/ rgba(255,255,255,.16)（neon） | 所有分隔线、卡片描边 |
| --ui-line-strong | rgba(20,16,22,.14) | 输入框、需要「是个控件」的地方 |

规则：
- **卡片不再用阴影**。层次靠「底色 + 1px 细线」表达；阴影只留给真正浮起来的层（弹窗、toast、拖拽幽灵块）。
- 玻璃模糊只保留在系统栏（侧栏 / 顶栏 / 底栏 / 弹窗），内容卡一律薄填充 + 细线。

## 3. 强调色

- 全站**只有一个强调色**（可读性算法给出的 --accent），使用比例 **< 5%**：
  主按钮、当前选中项、焦点环、关键进度条的填充。
- 其它地方一律中性：进度条底、标签、计数、图标块用 --ui-ink 的透明度分级。
- --accent-2 只允许出现在「渐变按钮」和「玻璃色相」里，不单独用于文字/图标。

## 4. 字体与字号（派生 + Apple 习惯）

| Token | 值 | 用途 |
| --- | --- | --- |
| --fs-display | 30px / 600 / -0.4px | 页面里唯一的大数字（总览的完成率、预算金额） |
| --fs-h1 | 20px / 600 / -0.2px | 页面标题（顶栏 h1） |
| --fs-h2 | 16px / 600 / -0.1px | 卡片标题、分组标题 |
| --fs-body | 14px / 400 / 1.6 | 正文、列表行 |
| --fs-cap | 12.5px / 400 / 1.5 | 说明、时间戳、单位 |
| --fs-micro | 11.5px / 500 | 角标、胶囊内文字 |

规则：
- 标题只用 **600**，正文 400，绝不 700/800；中文不加负字距（只有数字和英文标题加）。
- 数字用 font-variant-numeric: tabular-nums，同一列数字必须对齐。
- 一排里最多两种字号；出现第三种就说明该拆分了。

## 5. 间距 / 圆角（Apple base unit 8）

--sp-1:4px  --sp-2:8px  --sp-3:12px  --sp-4:16px  --sp-5:20px  --sp-6:24px  --sp-7:32px  --sp-8:48px

- 卡片内边距 **20px**（手机 16px），卡片间距 **16px**，分组之间 **32px**。
- 同一行卡片的标题基线必须齐；高度不一致的行用 align-items: stretch + 卡片内部 flex 撑满。
- 圆角：--r-xs:8px --r-sm:10px --r-md:14px --r-lg:18px --r-pill:999px。
  卡片 18，输入框/次级按钮 10，主按钮 pill，胶囊 pill。

## 6. 组件规则

- **卡片**：1px 细线 + 薄底；标题行 = 小图标块(20px 圆角 8) + 16px/600 标题 + 右侧最多 1 个文字动作（去待办 →）。标题行下留 12px。
- **按钮**：主按钮 pill + 强调色；次按钮 = 无边框文字按钮（--ui-ink-2，hover 变深）；危险操作 = 文字红。同屏主按钮**最多 1 个**。
- **胶囊/chip**：默认透明底 + 细线；选中 = 强调色 8% 底 + 强调色字；不再用彩色渐变胶囊。
- **列表行**：行高 ≥ 44px，行间 1px 细线（最后一行无线），左侧主信息 14px，右侧次要信息 12.5px 三级灰。
- **进度条**：4–6px 高、--r-pill、底为 --ui-ink @8%，填充只用强调色。
- **统计数字**：大数字 + 小单位（单位 12.5px 三级灰），不要用「0%」这种两个等大数字并排。
- **空态**：一个图标 + 一句 14px 说明 + 一个文字动作，不放大面积渐变。

## 7. 页面结构

- 顶栏：左侧 h1 + 一行 12.5px 副标题；右侧动作**最多 3 个**，其余收进「更多」。
- 桌面：侧栏 224px，选中项 = 中性填充 + 左侧 2px 强调色条 + 强调色文字（不再整条渐变）。
- 手机：底栏 4–5 项，当前项强调色文字 + 小圆点，不做滑块高亮（滑块已在可读性算法里）。
- 设置页：按「外观 / 数据与同步 / 提醒 / 应用」四组，组标题 16px/600 + 上方 32px 留白；每张卡只做一件事；默认折叠高级项。

## 8. Do / Don't

Do：
- 一屏一个视觉重点；次要信息用灰度和细线压下去。
- 同一种信息永远用同一种排版（今天/未来/逾期三个数都是「数字+单位」）。
- 留白换清晰度：宁可少放一张卡，也不要塞满。

Don't：
- 不要彩色渐变胶囊堆一屏（习惯列表已改中性行）。
- 不要给卡片加阴影、发光、双层描边。
- 不要在一行里塞 4 个以上平级按钮。
- 不要在标题里用 emoji 当图标——用统一尺寸的图标块（emoji 可以放块里）。

## 9. 响应式

- ≥1024px：侧栏 + 4 列卡片网格；卡片最小宽 220px。
- 768–1023px：侧栏收成图标条；网格 2 列。
- <768px：底栏；卡片单列，内边距 16px；顶栏动作只剩图标（hide-sm 文本隐藏）；主数字 26px。


## 10. 二级页面（v1.4.1）

> 一屏只放「有什么」，具体的调整点进去改。凡是「超过 4 个可调项」或「一年只改一次」的东西，都进二级页。

组件（src/components/SubPage.tsx）：
- `<SubPage title desc onBack right>` —— 二级页外壳：左上「‹ 返回」，标题 19px/600，副标题 12.5px 三级灰。**自带安卓返回键处理**（pushBackHandler），不用每处再写。
- `<SetRow icon title desc value onClick>` —— 设置列表行：图标块 26px + 标题 14px + 右侧当前值 13px 三级灰 + 灰色箭头。onClick 为空时渲染成静态行（用来展示只读信息）。

结构规则：
- 根页面按「外观 / 数据与同步 / 提醒 / 应用」四组，每组一张 `.card.set-list`，行间 1px 细线，行高 52px。
- 每行的右侧必须给出**当前值**（例：外观 → 「INS 奶油风」），用户点进去之前就知道现在是什么。
- 二级页里不再套「卡片套卡片」：直接是若干 `.set-group` / `.card`，每张卡只做一件事。
- 位置记在 `src/lib/uiNav.ts`（`openSettingsPage(id)` / `settingsPage()`），调试与测试钩子：`window.__schedule.ui.openSettingsPage('colors')`。
- 表单（新建/编辑记录）仍然是弹窗，不是二级页——弹窗适合「填完就关」，二级页适合「待一会儿来回调」。
- 标题版式：返回键单独占一行（左上），标题与副标题另起一行、左边缘和下面的卡片对齐。挤在同一行时标题会比卡片缩进一截，看着像没对齐。
- 二级页和根列表同宽（满宽），别给二级页加固定 max-width——宽度一变就像换了个应用；实在空旷的单个部件（如背景预览条）单独给 max-width。
- 设置页不显示右下角 💡 快捷记灵感按钮：它会浮在列表右侧盖住「当前值」，而设置页本来也用不上随手记（见 src/App.tsx 里 view !== 'settings' 的判断）。
